# WindWakerCOOP-PC releases

Online co-op for up to four players for the Wind Waker HD native PC port (a modified
[ZeldaWWHDRecomp](https://github.com/ZeldaWWHDRecomp/ZeldaWWHDRecomp)). Downloads are on the
[Releases](../../releases) page; this repository holds no source history, only release assets.

- **You need your own game:** The Legend of Zelda: The Wind Waker HD for Wii U (USA), as a disc image,
  Cemu archive or extracted folder. Releases contain no Nintendo game code, assets or keys; setup builds
  the game on your computer from your files.
- **Install:** unzip, start `WindWaker COOP.exe`, follow setup. **Update:** the launcher installs new
  releases itself and keeps your game files, saves and settings.
- **Play together:** everyone needs the same release. The host allows the UDP port (default 7777) in the
  firewall/router; clients join with `address:port`.
